# הערות שחרור — גרסה 2.2.3

גרסה 2.2.3 מוסיפה העתקת פרומפט ל־AI לכל נקודת עניין, בלי לחבר את האתר לשירות AI ובלי לחשוף מפתח API.

- בכל אחת מ־475 התחנות המפורסמות נוסף כפתור „העתקה ל־AI”.
- הכפתור זמין ב־45 מסלולי PASS וב־45 מסלולים עם הערה.
- הפרומפט אינו מוצג במסך: הוא מועתק ישירות ללוח כדי להדביקו ב־AI שבטלפון או במחשב.
- הפרומפט כולל את שם התחנה, סוגה, התקופה, תיאור הספר, הקשר המסלול, מצב הניווט, מידע מים אם קיים, אזהרת המסלול ומקורות כלליים של המסלול.
- הוא מבקש מן ה־AI לזהות את המקום בלי לנחש, לאמת מידע עדכני עם קישורים ותאריך, לציין סתירות ואי־ודאות, להכין תקציר קולי ולהציע חמש שאלות המשך.
- נוסף גיבוי העתקה מקומי לדפדפנים שאינם מאפשרים את Clipboard API; גם ההזמנה והתכנית המשולבת משתמשות בו.
- הכפתור נשאר פעיל וממוקד בזמן ההעתקה, והצלחת ההעתקה נמסרת גם באזור סטטוס נגיש בלי לחשוף את הפרומפט.
- גרסה 2.2.2 נשמרה במלואה תחת `versions/v2.2.2/` ולא נדרסה.
- נכסי PWA ממוספרים חדשים ומטמון `v2.2.3-build-2` מונעים ערבוב עם גרסה קודמת; טעינה והעתקה במצב offline נבדקו בפועל.

הגרסה מיועדת לסקירה מקומית בלבד עד לאישור מפורש של המשתמש. לא בוצעו commit, push או פרסום.
