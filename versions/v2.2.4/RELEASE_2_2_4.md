# הערות שחרור — גרסה 2.2.4

גרסה 2.2.4 מסווגת את 45 המסלולים עם ההערות לפי חומרת הבעיה ומבהירה למשתמש מה לעשות לאחר העתקת פרומפט ל־AI.

## מה חדש

- 6 מסלולים מסומנים „תיקון ניווט קטן”: הבעיה נקודתית בשם, ב־POI או בקישור המפה.
- 8 מסלולים מסומנים „מסלול מותנה”: אפשר לשקול אותם רק בתנאי המודגש, לאחר בדיקה עדכנית או בדילוג על נקודה מוגדרת.
- 31 מסלולים מסומנים „בעיה מהותית”: הציר או מוקד ליבה דורשים שינוי מהותי ואין להשתמש במפה הקיימת בלי תכנון מחדש.
- בטאב ההערות נוסף מדריך קצר, מונים מדויקים ומסנן נגיש לכל קטגוריה.
- הקטגוריה והנימוק המלא נשמרים בכרטיס, בפרטים, בהזמנה, בטיול משולב ובייצוא HTML.
- ה־Tooltip של „העתקה ל־AI” מסביר שהפרומפט מועתק ללוח ושיש לפתוח את חלון ה־AI הרצוי ולהדביק באמצעות Paste / הדבקה.
- לאחר לחיצה, הכפתור והודעת הנגישות מציגים גם את הצעד הבא במקום להסתפק בסימן ✓.
- נכסי PWA ממוספרים חדשים ומטמון `v2.2.4-build-1` מונעים ערבוב עם גרסה קודמת.

## מה לא השתנה

- 45 מסלולי PASS נשארו בטאב הראשי.
- 45 המסלולים עם ההערות נשארו זמינים לשיקול דעת ולא נמחקו.
- 53 מועמדי מחקר לא גמורים נשמרו בקבצים ואינם מפורסמים.
- כל 475 התחנות ממשיכות להציע העתקת פרומפט בלי להציגו, לשמור אותו או לשלוח אותו מן האתר.
- לאחר אישור המשתמש הגרסה נסגרה ב־commit, נשלחה ל־`main` ופורסמה באתר GitHub Pages.
