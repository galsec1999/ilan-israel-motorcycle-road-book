# ספר הטיולים של אילן — גרסה 2.2.0 — מסמך שחרור

גרסה 2.2.0 סוגרת את עוזר המסלול המקומי לכל 143 המסלולים, משמרת את מעמד האימות האמיתי של כל תיק ומיישרת את גרסת האתר, ה־manifest, קובצי הנתונים וה־Service Worker.

## מצב השחרור

- 143 תיקי מסלול נוצרים באופן דטרמיניסטי.
- 659 תחנות מקבלות מזהים ייחודיים.
- 42 תיקים מאומתים, 48 תיקים מוגבלים ו־53 תיקי מועמד מוגבלים.
- עוזר המסלול המקומי זמין בכל כרטיס ובכל תחנה.
- שירות AI בענן נשאר אופציונלי, כבוי ולא פרוס.
- גרסה 2.1.2 נשמרה במלואה תחת `versions/v2.1.2/`.

תיק טכני שלם אינו הצהרת אימות: המועמדים נשארים מסומנים כמועמדים ואינם מוצגים כמסלולי רכיבה מאושרים.
