# Worker לעוזר המסלול ולשירות AI אופציונלי — גרסה 2.2.0

שירות Serverless אופציונלי לספר הטיולים. האתר הסטטי פועל גם בלעדיו באמצעות עוזר מסלול מקומי והקראה של המכשיר. ה־Worker אינו פרוס ואינו מחובר לגרסה 2.2.0.

## כיסוי תיקי המסלול

הקובץ `src/context.generated.js` נבנה מתוך שני מאגרי הנתונים וכולל בדיוק:

- 42 מסלולי מקור במעמד `route_scope`.
- 48 מסלולי מקור במעמד `limited_route_scope`.
- 53 מועמדים במעמד `candidate_scope`.
- 143 תיקים ו־659 תחנות בסך הכול.

מעמד התמיכה אינו משנה את מעמד האימות. במועמדים נשמרים שדות חסרים כ־`null`, וה־prompt מחייב לציין שזה אינו מסלול רכיבה מאושר.

## גבולות בטיחות

- המפתח `OPENAI_API_KEY` נשמר רק כסוד של סביבת השרת.
- הלקוח שולח `route_id`, ‏`stop_id` ושאלה בלבד.
- השרת שולף הקשר רק מתוך `context.generated.js`; המשתמש אינו יכול להחליף את חומר המקור.
- התשובה מוגבלת לחומר שבתיק ולמעמד האימות שלו.
- המקורות משויכים ברמת המסלול, לא כציטוט מדויק לכל טענה.
- אין מידע חי על חסימות, מזג אוויר, מצב ביטחוני או מצב אספלט.
- `store:false` בכל קריאת Responses API.
- כתובת לא מוכרת, מזהה מסלול לא מוכר או מזהה תחנה לא מוכר נדחים לפני קריאת ספק.
- אין פריסה, חיוב או חיבור מפתח במסגרת גרסה 2.2.0.

## בנייה ובדיקות

```powershell
node ..\tools\build-ai-context.mjs
node --check src\worker.js
node --check src\context.generated.js
node --test test\context.test.js test\worker.test.js
```

המחולל נכשל אם מספר המסלולים או התחנות משתנה בלי עדכון מפורש, אם יש מזהה כפול, אם חסר מקור או אם הפניית תחנה מצביעה למקור שאינו בתיק.

## הגדרות נדרשות לפני פריסה עתידית

1. להעתיק `wrangler.toml.example` ל־`wrangler.toml` ולהגדיר KV להגבלת שימוש.
2. לקבוע `OPENAI_API_KEY` ו־`SESSION_HMAC_SECRET` באמצעות `wrangler secret put`.
3. לבחור ולבדוק מודל טקסט ומודל TTS זמינים באמצעות משתני הסביבה.
4. להגביל `ALLOWED_ORIGIN` ל־origin המדויק של האתר.
5. להריץ בדיקות, מבחן האזנה אנושי בעברית, בדיקת פרטיות ובדיקת עלויות לפני deploy.
6. רק לאחר פריסה מאומתת להגדיר באתר `aiEndpoint` ולהפעיל `allowCloudAi`.
