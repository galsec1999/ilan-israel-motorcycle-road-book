# ספר הטיולים של אילן — גרסת מסמך 1.1.1 — תיקיית PWA

תיקייה זו מוכנה להצגה ולהתקנה כאפליקציה בכרום.

## הפעלה מקומית

יש להפעיל את `הפעלה_מקומית_בכרום.cmd`. הקובץ מעלה שרת מקומי בכתובת `http://localhost:4173/` ופותח את Chrome. כפתור **התקנת האפליקציה** יופיע מעל הספר; אפשר להתקין גם מתפריט Chrome.

פתיחה ישירה של `index.html` באמצעות `file://` תציג את הספר, אבל הדפדפן לא יאפשר התקנת PWA. לצורך התקנה נדרש `localhost` או אתר HTTPS.

## העלאה עתידית לאינטרנט

יש להעלות את כל תוכן התיקייה, ללא שינוי במבנה, לתיקייה ציבורית בשרת HTTPS. אין צורך ב־GitHub דווקא. לאחר עדכון של `book.html` או קבצי המעטפת, יש לשנות את הערך `CACHE_NAME` ב־`sw.js` כדי שמכשירים מותקנים יקבלו את הגרסה החדשה.

## מגבלות צפויות

- תוכן הספר נשמר לשימוש לא מקוון לאחר טעינה מוצלחת אחת.
- מפות Google, Waze, חיפושים וקישורים חיצוניים דורשים חיבור לאינטרנט.
- הספר המקורי נשמר כ־`book.html` ללא שינוי בתוכנו.
