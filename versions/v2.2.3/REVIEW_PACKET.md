## 5. בעיות, מגבלות וסיכונים

- מסלול WARNING אינו מסלול מאושר; ההערה עשויה להתייחס לסגירה, דרך עפר, ניווט שגוי, דרך פרטית או מקור סותר.
- מצב כבישים, אתרים ומקורות חיצוניים יכול להשתנות אחרי 09.08.2026.
- מפות וניווט דורשים אינטרנט; האתר עצמו זמין offline לאחר טעינה ראשונה.
- הפרומפט משתמש במקורות ברמת המסלול, לא בציטוט נקודתי לכל תחנה; הנוסח מצהיר על כך ודורש אימות חיצוני.
- מסלול הגיבוי במקרה של חסימת Clipboard API מכוסה בבדיקות קוד וניקוי `finally`, אך לא נכפה בדפדפן משום שכלי הבדיקה אינו מאפשר monkey-patch. מסלול ההעתקה הרגיל נבדק בפועל ב־Chrome ובמצב offline.
- כפתור ההתקנה נצפה ב־Chrome, אך התקנה מלאה למערכת ההפעלה לא בוצעה בסבב הזה.
- האתר המקומי טרם פורסם, ולכן לא בוצעה בדיקת כתובת GitHub Pages חיה בסבב הזה.
