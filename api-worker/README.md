# שירות AI לספר הטיולים — גרסת מסמך 2.0.3

שירות Serverless אופציונלי לגרסת מוצר 2.0. האתר הסטטי פועל גם בלעדיו ומציג טקסט מקומי והקראה באמצעות Chrome.

## גבולות בטיחות

- המפתח `OPENAI_API_KEY` נשמר רק כסוד של סביבת השרת.
- הלקוח שולח `route_id`, ‏`stop_id` ושאלה בלבד.
- השרת שולף הקשר מתוך `context.generated.js`; המשתמש אינו יכול להחליף את חומר המקור.
- רק מסלולים שמסומנים `מאומת ממקורות` נכנסים להקשר.
- המקורות הישנים משויכים ברמת המסלול, ולכן התשובה מסומנת `route_scope` ולא כציטוט מדויק לכל טענה.
- אין מידע חי על חסימות, מזג אוויר, מצב ביטחוני או מצב אספלט.
- `store:false` בכל קריאת Responses API.
- אין פריסה, חיוב או חיבור מפתח במסגרת גרסת העבודה המקומית.

## הגדרות נדרשות לפני פריסה

1. להעתיק `wrangler.toml.example` ל־`wrangler.toml` ולהגדיר KV להגבלת שימוש.
2. לקבוע `OPENAI_API_KEY` ו־`SESSION_HMAC_SECRET` באמצעות `wrangler secret put`.
3. לבדוק מחדש זמינות מודל טקסט ומודל TTS. המודלים ניתנים להחלפה במשתני סביבה.
4. להגביל `ALLOWED_ORIGIN` לכתובת האתר המדויקת.
5. להריץ בדיקות, מבחן האזנה אנושי בעברית ובדיקת עלויות לפני deploy.
