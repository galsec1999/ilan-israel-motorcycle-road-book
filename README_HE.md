# ספר הטיולים של אילן — גרסת מסמך 4.4.1

גרסת המוצר הנוכחית היא **4.4.1**. זוהי תיקיית הפרסום הסגורה של ה־PWA בעברית וב־RTL, המפורסמת באמצעות GitHub Pages.

## מה כלול בגרסה 4.4.1

- 361 רשומות קטלוג פעילות; לכל רשומה לפחות שתי נקודות ניווט לאחר התאמת 81 רשומות שנשמרו במבנה נתונים ישן.
- רשומה 261 נבנתה מחדש כמסלול בטוח למעלה עקרבים ונחל גוב: גישה מכביש 90 ועיר אובות, חזרה באותו קטע של כביש 227 וללא חציית המעלה הסגור.
- בדיקת הקטלוג מאמתת כעת בפועל התחלה, סיום, תוכן, פרופיל כביש ולפחות שתי נקודות מפה — ולא מסתפקת בדגל PASS שנשמר ברשומה.
- קישורי לולאה ישנים עם התחלה וסיום זהים מפוצלים אוטומטית לשני קישורי Google Maps — הלוך וחזרה — כדי למנוע כשל חישוב מסלול.

- 90 המסלולים המקוריים, 18 מסעות בני יומיים ושלושה מסעות גדולים נשמרו.
- 53 צירים נוספים מפורסמים במעמד גלוי של **„מועמד באימות”**. לא הומצאו להם מרחק, זמן או אישור דרך.
- לכל 143 המסלולים נוצר תיק מסלול לעוזר: 42 תיקים במעמד מאומת, 48 תיקים במעמד מוגבל לפי סטטוס המסלול ו־53 תיקי מועמד מוגבלים.
- 659 תחנות מקבלות מזהה קבוע בתיקי העוזר. בתיקי מועמד ההסבר מציין במפורש שטרם נוסף מידע עובדתי מאומת.
- מסננים מנורמלים לפי אזור, רמת רכיבה, אופי כביש ורמת אימות.
- מפה עצלה לכל כרטיס וקישור מלא ל־Google Maps; קישורי Waze לעצירות.
- Dark Mode לפי המערכת ובבחירה ידנית.
- מרכז בטיחות מלא למוביל, מאסף, מרשלים, רכיבה מדורגת, מרחקים ומיגון.
- כתב ויתור, הודעת שימוש ראשון ואיסור שימוש באתר בזמן רכיבה.
- שמירת מסלולים מקומית; בחירות ישנות מן המפתח `roadTripCombinedV02` מיובאות בלי למחוק את נתוני גרסה 1.
- ייצוא HTML, מחולל הזמנות ו־WhatsApp, בונה טיול משולב, חיבורי המשך, פרופיל כביש, שער איכות, אוכל, מים וחיפושי תדלוק.
- לכל מסלול ניתן להגדיר נקודת מפגש במרכז ונקודת הצטרפות שנייה, עם שעות משוערות ועריכה ידנית. הנתונים משולבים בהזמנה ובקובץ המיוצא.
- מונה מקומי גלוי סופר כניסה אחת לכל הפעלת דפדפן. מונה גלובלי יופעל רק לאחר חיבור שירות שרת אמין.
- הקראה מקומית בעברית באמצעות מנגנון הדיבור של המכשיר.

## עוזר המסלול ושירות AI אופציונלי

„עוזר המסלול” הוא השם של התכונה הזמינה באתר. הוא מחזיר ישירות מידע מתוך תיק המסלול המקומי ומציג את מעמד האימות שלו. הוא אינו מוצג כמודל AI ואינו משלים עובדות שאינן בספר.

התיקייה `api-worker/` מכילה backend אופציונלי לשירות AI עתידי. המאגר הוותיק של העוזר כולל 143 תיקי מסלול, מגביל את התשובה לחומר הספר ומחזיר ללקוח את רמת התמיכה האמיתית: `route_scope`, ‏`limited_route_scope` או `candidate_scope`. השירות אינו פרוס ואינו מחובר לאתר בגרסה 4.4.1: ‏`aiEndpoint` ריק ו־`allowCloudAi` כבוי. אין להכניס `OPENAI_API_KEY` ל־HTML, ל־JavaScript, ל־GitHub Pages או למאגר.

לפני חיבור שירות ענן יש לבחור מודלים זמינים באמצעות משתני הסביבה, להגדיר סודות רק בשרת, לבדוק עלויות, לבצע בדיקות אינטגרציה חיות ולהאזין אנושית לקול העברי.

## הפעלה מקומית והתקנה בכרום

הפעילו את `הפעלה_מקומית_בכרום.cmd`. הקובץ מפעיל שרת מקומי בכתובת `http://localhost:4173/` ופותח את Chrome.

פתיחה ישירה של `index.html` ב־`file://` מציגה את התוכן, אך PWA ו־Service Worker דורשים `localhost` או HTTPS. כפתור **התקנת האפליקציה** מופיע רק כאשר Chrome מחזיר אירוע התקנה תקין; אפשר להתקין גם מתפריט Chrome.

## בדיקות מקומיות

מתוך התיקייה:

```powershell
node tools\build-ai-context.mjs
node --check assets\app-v2.js
node --check sw.js
node --check api-worker\src\worker.js
node --test tests\validate-v2.mjs
node --test api-worker\test\context.test.js api-worker\test\worker.test.js
```

## מגבלות ידועות

- תיק מסלול מלא מבחינה טכנית אינו הופך מסלול למאומת. 53 המועמדים עדיין דורשים Place IDs או קואורדינטות, בדיקת דרך סלולה, מרחק, זמן ונסיעת ביקורת.
- המקורות משויכים ברמת המסלול ולא לכל טענה או תחנה בנפרד.
- מפות, Waze וקישורים חיצוניים דורשים חיבור לאינטרנט.
- אין עדיין מאגר תמונות בעל רישיון וקרדיט לכל מסלול; תצוגת המפה משמשת כתצוגה חזותית בלי להעתיק תמונות מוגנות.
- `robots.txt` ו־`noindex` מצמצמים גילוי במנועי חיפוש אך אינם מגינים בסיסמה. כל מי שמקבל את הקישור יכול לפתוח ולהעביר אותו.
