# ספר הטיולים של אילן — גרסה 2.2.4

זוהי תיקיית הפרסום המבוקרת של גרסה 2.2.4. האתר בנוי כ־PWA בעברית וב־RTL ומתאים להפעלה מקומית או לפרסום ב־GitHub Pages. גרסה זו מפרידה בין מסלולי PASS לבין מסלולים עם בעיה ידועה, מסווגת כל בעיה לפי חומרתה, ומסבירה למשתמש כיצד להעתיק מכל תחנה פרומפט ולהדביקו ב־AI שבחר.

## מצב הקטלוג בגרסה 2.2.4

- כל 143 רשומות המסלול נסרקו בנפרד: 90 מסלולי מקור ו־53 מועמדי מחקר.
- 45 מסלולי מקור עברו את שער השחרור ומופיעים בטאב הראשי כ־PASS.
- 45 מסלולי מקור נוספים מופיעים בטאב „מסלולים עם הערות”: 6 „תיקון ניווט קטן”, 8 „מסלול מותנה” ו־31 „בעיה מהותית”. בכל כרטיס, בחלון הפרטים, בהזמנה ובייצוא מוצגים גם הקטגוריה וגם הנימוק המלא; הם אינם מוצגים כ־PASS.
- כל 53 מועמדי המחקר נשמרו ב־`data/new-routes-v2.js`, אך אינם מפורסמים עד להשלמת מרחק, זמן, כבישים, תדלוק, תוכן ובדיקת דרך.
- ב־45 מסלולי ה־PASS יש 240 תחנות ו־99 כתובות מקור ייחודיות. דוחות 2.2.4 מפרידים את נתוני 45 מסלולי האזהרה ואת שלוש הקטגוריות.
- צילומים מלאים של גרסאות 2.2.0, ‏2.2.1, ‏2.2.2 ו־2.2.3 נשמרו תחת `versions/`; חומר המקור לא נדרס ולא נמחק.

דוח JSON ודוח קריא לאדם נשמרים תחת `reports/` ומציגים תוצאה לכל אחת מ־143 הרשומות.

## מה נבדק

- שדות החובה, מרחק, זמן, רמה, עונה, כבישים, תדלוק, אזהרות, תחנות ופרופיל כביש.
- רצף נקודות הניווט, התחלה וסיום, מסלול מעגלי לעומת נקודה־לנקודה, מגבלת נקודות ואורך URL.
- פתיחה בפועל של מפות Google, זיהוי גאוקוד שגוי, חציית גבולות, כבישי אגרה, דרכים פרטיות או מוגבלות ומסלולים חלקיים.
- תקינות כתובות המקור והתאמתן למסלול, כולל סגירות, דרכי עפר, מגבלות גישה ותיאום מראש.
- כל כרטיסי המסלול וחלונות הפרטים, מפות מוטמעות, מובייל RTL, מצב כהה והיעדר גלילה או קטיעה אופקית.
- ייצוא מסלול ל־HTML, יצירת הזמנה, נקודות מפגש, שילוב מסלולים, מסלולי המשך ומונה כניסות מקומי.
- העתקה בפועל של פרומפט מתחנת PASS ומתחנת WARNING, כולל קריאה חוזרת של הלוח ואימות שהאזהרה המלאה נשמרת.
- manifest, סמלי האפליקציה, Service Worker, מטמון, מצב offline ונתיבי משנה של GitHub Pages.

## תכונות פעילות

- מפה עצלה בכל כרטיס וקישור מלא ל־Google Maps; קישורי Waze ניתנים רק לנקודות חד־משמעיות.
- סינון לפי אזור, רמת רכיבה, אופי כביש, סוג טיול ורמת אימות.
- מדריך וסינון נפרד לשלוש קטגוריות ההערה, עם מונים, צבעים והסבר ברור לכל רמה.
- Dark Mode לפי המערכת ובבחירה ידנית.
- מרכז בטיחות למוביל, מאסף ומרשלים, רכיבה מדורגת, מרחקים, מיגון ואחריות אישית.
- כתב ויתור, הודעת שימוש ראשון ואיסור שימוש באתר בזמן רכיבה.
- שמירת מסלולים מקומית, ייצוא HTML, הזמנות ו־WhatsApp, ובונה טיול משולב.
- כפתור „הוספה לשילוב למרות ההערה” מתעד החלטה מפורשת, וההערה נשמרת בכל תכנית או ייצוא.
- נקודת מפגש במרכז ונקודת הצטרפות שנייה עם שעות משוערות ועריכה ידנית.
- מונה מקומי גלוי הסופר כניסה אחת לכל הפעלת דפדפן. אין מונה גלובלי ללא שירות שרת.
- הקראה מקומית בעברית באמצעות מנגנון הדיבור של המכשיר.
- בכל אחת מ־475 התחנות יש כפתור „העתקה ל־AI”. ה־Tooltip מסביר שהפרומפט מועתק ללוח ושלאחר מכן יש לפתוח את חלון ה־AI הרצוי ולהדביק באמצעות Paste / הדבקה. גם המשוב לאחר הלחיצה מציג את הצעד הבא במקום ✓ בלבד.

## עוזר המסלול ו־AI

עוזר המסלול המקומי מציג רק מידע שכבר נמצא בספר במסלולי ה־PASS. בנוסף, כפתור „העתקה ל־AI” זמין בכל תחנה — גם במסלולים עם הערה — כדי להדביק בקשה מובנית ב־ChatGPT או ב־AI אחר במכשיר. הפרומפט אינו מוצג, נשמר או נשלח בידי האתר. הוא דורש מן ה־AI לזהות את המקום, לאמת מידע עדכני, לציין סתירות ואי־ודאות, להציע הרחבה וחמש שאלות המשך, ולהבדיל בין עובדות למסקנות. מקורות המצורפים לפרומפט מסומנים כמקורות כלליים של המסלול ולא כציטוטים נקודתיים.

שירות AI בענן של האתר נשאר אופציונלי, כבוי ולא פרוס; אסור להכניס `OPENAI_API_KEY` ל־HTML, ל־JavaScript, ל־GitHub Pages או למאגר.

## הפעלה מקומית והתקנה בכרום

הפעילו את `הפעלה_מקומית_בכרום.cmd`. הקובץ מפעיל שרת מקומי בכתובת `http://localhost:4173/` ופותח את Chrome.

פתיחה ישירה של `index.html` ב־`file://` מציגה תוכן, אך התקנת PWA ו־Service Worker דורשות `localhost` או HTTPS. כפתור **התקנת האפליקציה** מוצג לאחר ש־Chrome מחזיר אירוע התקנה; אפשר להתקין גם מתפריט Chrome.

## בדיקות מקומיות

מתוך התיקייה:

```powershell
node --check assets\app-v2.2.4.js
node --check data\release-audit-v2.2.4.js
node --check sw.js
node --check tools\audit-release-routes.mjs
node --test tests\validate-v2.mjs
node tools\audit-release-routes.mjs --network --write
```

הפקודה האחרונה מריצה מחדש את ביקורת הרשת וכותבת את דוחות השחרור. אין לפרסם אם אחת מן הבדיקות נכשלת.
